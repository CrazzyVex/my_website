Amora

Amora is a smart inventory and business operations platform built to help teams manage products, stock, locations, transfers, viewing rooms, and role-based access in one workspace.

Amora opens into the workflows teams need every day.

React Supabase JavaScript SQL Authentication RLS Netlify Responsive UI
Feature 01

Product Management

Create, update, and organize product information in one structured place instead of spreading product data across disconnected sheets.

Feature 02

Location Management

Manage warehouses, storage points, or business locations and connect inventory records to the right place.

Feature 03

Inventory Tracking

Track stock across locations and understand what is available, where it is stored, and how it changes over time.

Feature 04

Stock Transfers

Move stock between locations through a structured transfer workflow instead of manually editing multiple records.

Feature 05

Viewing Rooms / Catalogue

Create clean catalogue-style product views that can be used to present selected products to clients, internal teams, or stakeholders.

Feature 06

Team Workspaces

Support team-based usage where users work inside shared business workspaces.

Feature 07

Role-Based Access

Control what different users can view, create, edit, or manage using roles such as Administrator, Manager, Staff, and Viewer.
